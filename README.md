# Mehul Singh — Portfolio

Static, single-file-per-page portfolio site.

- `index.html` — landing page (bio, résumé link, both case studies, contact)
- `rails-calendar-case-study.html` — redRail Calendar case study
- `seat-switch-case-study.html` — IRCTC Error Handling & Seat Switch case study
- `resume.pdf` — résumé, linked from the landing page
- `assets/` — screenshots and images used by the case studies

No build step — plain HTML/CSS/JS. To preview locally, just open `index.html` in a browser.

## Hosting on GitHub Pages

1. Push this folder to a GitHub repo (see the commands you were given alongside this README).
2. In the repo, go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to `Deploy from a branch`, branch `main`, folder `/ (root)`.
4. Save. GitHub will publish the site at `https://<your-username>.github.io/<repo-name>/` within a minute or two.
